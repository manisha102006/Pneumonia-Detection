# Pneumonia Detection from Chest X-Ray Images

This is a deep learning project for detecting pneumonia from chest X-ray images. The images are classified into two categories: Normal and Pneumonia.

For this project, I used a basic CNN model and also used MobileNetV2 with transfer learning. The performance of both models was compared using test accuracy.

The basic CNN achieved an accuracy of 71%, while MobileNetV2 achieved an accuracy of about 86%.

I used Python, TensorFlow, Keras, NumPy, Matplotlib and Scikit-learn for this project.

A sample X-ray image was also tested using the trained MobileNetV2 model, and the prediction was Normal.

This project was done for learning and educational purposes.
